# Shirakami Fubuki

## 📌 Description

A web application built to introduce the Shirakami Fubuki Discord Bot to server administrators and community members. The platform serves as a central hub for exploring bot features, viewing command guides, and accessing official legal documentation required for Discord Application Verification.

---

## ✨ Bot Key Features

1. **Persona-Driven Conversational AI:** Interacts using canonical lore, character traits, and iconic catchphrases while maintaining strict character boundaries (including "Best Friend" status and fox identity enforcement).
2. **Contextual User Memory:** Retains user preferences and past interaction context across sessions to deliver continuous, personalized conversations.
3. **Multi-Language Support:** Provides localized interactions in English, Indonesian, and Japanese to support diverse global communities.
4. **Interactive Slash Commands:** Features intuitive slash commands for direct chatting, language configuration, memory deletion, and viewing command guides.
5. **Versatile Chat Integration:** Responds naturally when mentioned in server text spaces or engaged through direct messages.
6. **Privacy Controls:** Includes dedicated memory management tools that empower users to erase their stored conversation history at any time.
